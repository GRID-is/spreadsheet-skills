Hi,

I maintain the agent skills for GRID (grid.is), the company behind an Excel-compatible spreadsheet
engine for JavaScript, and I'd like to ask for an Official listing for our repo:

https://github.com/GRID-is/spreadsheet-skills (https://skills.sh/GRID-is/spreadsheet-skills)

What it is:

- 13 skills covering our four npm packages: the headless spreadsheet engine
  (`@grid-is/spreadsheet-engine`), a React viewer and editor, and `@grid-is/agent-tools`, an MCP
  server that lets an agent load, calculate, edit and debug .xlsx files.
- Skills are task-shaped and narrow (spreadsheet-engine, xlsx-generation, spreadsheet-what-if,
  excel-formula-debugging, spreadsheet-mcp, and so on), each with a search-first description.
- The API reference inside each skill is generated from the type definitions shipped in our
  published packages, and the tool catalogue is generated by calling the package. A lint fails CI if
  a skill's code example uses an identifier the package does not export, and a weekly Action opens a
  PR when a package release changes the API. The skills also tell the agent to prefer the installed
  package's own types when they are newer.
- We publish the repo from the GRID-is GitHub organisation, the same org as the packages and the
  docs at docs.grid.is, and we link the install command from our docs and package READMEs.

The repo has a `skills.sh.json` grouping the skills into three sections. Let me know if you need
anything else from our side, for example a verification file or a change to the metadata.
